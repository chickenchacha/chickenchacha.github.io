# 🐔 치킨차차 역사게임

보드게임 **치킨차차(Chicken Cha Cha Cha)** 의 규칙을 그대로 옮기고, 타일 그림을 우리 역사 속 위인 12명으로 바꾼 웹 게임입니다. 초등학교 수업에서 전자칠판이나 교실 PC로 바로 띄워 쓰도록 만들었습니다.

## 바로 실행하기

| 버전 | 주소 | 스마트폰에서 달걀 타일 |
|---|---|---|
| 버전 1 | <https://chickenchacha.github.io/> | 그림 위인 12명 · 스마트폰에서 **이름**만 표시 |
| 버전 2 | <https://chickenchacha.github.io/v2/> | 그림 위인 12명 · 스마트폰에서도 **그림** 표시 |
| 버전 3 | <https://chickenchacha.github.io/v3/> | **실제 인물 사진** 12명 (조선~일제강점기) |
| 버전 4 | <https://chickenchacha.github.io/v4/> | 버전 3과 같되, **사진을 직접 바꿀 수 있는 편집판** |

세 버전은 규칙과 기능이 완전히 같고 등장 인물과 타일 그림만 다릅니다. 수업에서 어느 쪽이 잘 맞는지 비교해 보고 고르시면 됩니다.

**버전 1·2 인물** — 단군왕검 · 광개토대왕 · 이순신 장군 · 장보고 · 세종대왕 · 신사임당 · 정약용 · 김유신 장군 · 김구 · 안중근 의사 · 유관순 열사 · 장영실

**버전 3 인물** — 세종대왕 · 이순신 · 신사임당 · 율곡 이이 · 퇴계 이황 · 고종황제 · 김구 · 안창호 · 안중근 · 윤봉길 · 홍범도 · 유관순

각 버전은 HTML 파일 하나로 동작합니다. 별도 설치나 서버 없이 브라우저로 열면 바로 게임이 시작됩니다. 인물 그림은 모두 파일 안에 포함되어 있어, 한 번 열고 나면 인터넷이 끊겨도 게임이 계속 돌아갑니다.

## 게임 방법

1. **준비** — 참가 인원(2~6명)과 각 닭이 가질 꽁지(깃털) 개수(1개 또는 2개)를 정하고 시작합니다. 달걀 타일 24장은 인물당 2장씩 타원형 트랙에 무작위로 놓이고, 가운데에는 팔각형 타일 12장이 인물당 1장씩 뒤집힌 채 놓입니다.

2. **차례 진행** — 자기 차례가 되면 가운데 팔각형 타일 하나를 클릭해 뒤집습니다. 내 닭 바로 앞 달걀 타일(노란 테두리로 표시됨)의 인물과 같으면 한 칸 전진하고, 계속 이어서 도전할 수 있습니다. 다르면 타일은 제자리에 다시 덮이고 다음 사람 차례로 넘어갑니다.

3. **앞지르기와 꽁지 뺏기** — 내 앞에 다른 닭이 있으면 그 닭 너머의 달걀 타일이 목표가 됩니다. 맞히면 그 닭을 뛰어넘으면서 상대의 꽁지를 모두 빼앗아 옵니다.

4. **승리** — 다른 닭들의 꽁지를 모두 모은 사람이 이깁니다.

시작 화면에서 **PC · 전자칠판 / 스마트폰** 중 어떤 기기로 할지 고릅니다. 좁은 화면으로 접속하면 스마트폰이 자동으로 선택됩니다. 타일 크기는 화면 크기에 맞춰 자동으로 계산되므로 기종을 가리지 않고 타일이 겹치거나 화면 밖으로 잘리지 않습니다.

## 교실에서 쓰기 좋은 점

- 가운데 팔각형 타일에 **1~12번 번호**가 붙어 있어, 학생이 "7번 뒤집어 주세요"라고 말하면 교사가 눌러줄 수 있습니다.
- 지금 차례인 사람은 오른쪽 위 이름표와, 말이 커지고 진해지는 것으로 함께 표시됩니다.
- 노트북·전자칠판 화면에 스크롤 없이 한 화면으로 들어오도록 배치했습니다.
- 다크 모드에서도 그대로 잘 보입니다.

## 만든 것

순수 HTML/CSS/JavaScript 한 파일. 외부 라이브러리나 빌드 과정이 없습니다.

## 다른 PC에서 이어서 작업하기

이 저장소만 있으면 어느 PC에서든 작업할 수 있습니다. 인물 그림 원본도 `assets/characters/` 에 함께 들어 있습니다.

**1. 내려받기** — 새 PC에서 Git이 설치돼 있어야 합니다 ([git-scm.com](https://git-scm.com)).

```bash
git clone https://github.com/chickenchacha/chickenchacha.github.io.git
```

**2. 수정하고 올리기**

```bash
git pull
# ... 파일 수정 ...
git add -A
git commit -m "무엇을 바꿨는지 한 줄"
git push
```

`git push`를 처음 할 때 GitHub 로그인 창이 뜹니다. 한 번 로그인하면 그 PC에 기억됩니다.

**3. 작업 시작 전에는 항상 `git pull`** — 다른 PC에서 바꾼 내용을 먼저 받아와야 충돌이 안 납니다.

푸시하면 1~2분 뒤 웹 주소에 자동으로 반영됩니다.

> **주의:** 클론은 OneDrive·구글드라이브 같은 동기화 폴더 **밖에** 두세요. 동기화 폴더 안에 두면 `.git` 폴더가 두 PC에서 동시에 동기화되면서 저장소가 깨질 수 있습니다. `C:\projects\` 처럼 평범한 폴더를 쓰세요.

```
index.html                버전 1 (스마트폰에서 이름 타일)

assets/characters-v3/     버전 3 인물 사진 원본 12장 (1080x1080)
```

## 사진 바꾸기 (코드 수정 없이)

[버전 4](https://chickenchacha.github.io/v4/)에서 시작 화면의 **[🖼 인물 사진 바꾸기]** 버튼을 누르면 12명의 사진과 이름을 직접 교체할 수 있습니다. 사진은 브라우저 안에서 320×320 JPEG로 자동 축소되므로 원본 크기는 신경 쓰지 않아도 됩니다.

바꾼 사진은 **그 기기에만** 저장됩니다. 다른 사람에게 배포하려면 **[💾 HTML 파일로 내보내기]** 를 눌러 받은 `index.html`을 이 저장소에 올리면 됩니다.

> 참고: 누가 접속해 사진을 바꿔도 그 사람 기기에서만 바뀝니다. 공개된 게임은 저장소에 파일을 올릴 수 있는 사람만 바꿀 수 있습니다.

인물 그림은 HTML 안에 base64로 박혀 있습니다. 코드로 직접 바꾸려면 원본 폴더의 파일을 교체한 뒤 HTML 안의 `CHARACTERS` 배열을 다시 만들어 넣으면 됩니다. 버전 3의 사진은 원본이 장당 500KB가 넘어 그대로 넣으면 너무 무겁기 때문에, 320×320 JPEG로 줄여서 넣었습니다(12장 합계 약 208KB).
